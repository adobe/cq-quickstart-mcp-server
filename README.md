# Adobe Experience Manager Quickstart MCP Server 

MCP Server running on top of the AEM Quickstart. 

## Usage

For installation and setup instructions, see [Local development with AI tools](https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/ai-in-aem/local-development-with-ai-tools#aem-quickstart-mcp-server).

## Supported AEM-CS SDK versions

The MCP server has been validated with SDK versions `2026.2.24678.20260226T154829Z-260200` or newer
but should support any recent versions of the AEM-CS SDK.
